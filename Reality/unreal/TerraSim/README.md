# TerraSim — native Unreal Engine edition

This project runs directly in Unreal Engine 5.8, using Metal on macOS. It is separate from the existing browser application, which remains available and contains the broader astronomy laboratory.

## Native rendering

- WGS84 globe geometry at real centimetre scale, with double-precision actor/camera coordinates.
- Unreal SkyAtmosphere centred on Earth: Rayleigh/Mie scattering, actual planetary scale, real solar illumination, thin atmospheric limb, and a physical day/night boundary.
- 8K day, normal, water-specular, night, and cloud maps. PBR ocean highlights and land roughness; native deferred renderer and TSR.
- A navigable azimuthal-equidistant flat disc. Its local point-Sun height is editable. Its illumination uses analytic Lambertian radiance with inverse-square attenuation and fixed source power, referenced to 110,000 lux at 5,000 km, to avoid native point-light precision limits at planetary distances. Atmospheric and gravity assumptions remain explicitly hypothetical.
- A separate Mont Blanc terrain scene built from real DEM data and satellite imagery, with no vertical exaggeration. Its geometry spans approximately 27 km; it is a bounded demonstration, not worldwide streaming.
- Matching Cesium for Unreal 2.30 / UE 5.8 plugin is installed in the project. No ion token is bundled or read from accounts. Connecting worldwide Cesium services remains a separate account/data configuration step.

## Build / generate assets

The engine is installed at `/Users/Shared/Epic Games/UE_5.8`. Build the editor target:

```sh
"/Users/Shared/Epic Games/UE_5.8/Engine/Build/BatchFiles/Mac/Build.sh" \
  TerraSimEditor Mac Development -Project="$(pwd)/TerraSim.uproject" \
  -architecture=arm64 -MaxParallelActions=4
```

Generate imported assets and levels using the editor's Python plugin:

```sh
"/Users/Shared/Epic Games/UE_5.8/Engine/Binaries/Mac/UnrealEditor.app/Contents/MacOS/UnrealEditor" \
  "$(pwd)/TerraSim.uproject" -ExecutePythonScript="$(pwd)/Content/Python/build_terrasim.py" -ansimalloc -unattended
```

The script creates `/Game/TerraSim/Maps/Earth` and `/Game/TerraSim/Maps/Alps`, and imports textures/materials. Source raster imagery lives in the parent web application's `public/textures`. Terrain assets are generated by `Scripts/prepare_alps.py`; cached downloads are reused and network requests are limited to four at a time.

Double-click `Launch TerraSim.command` to open Earth. `Scripts/launch.sh Earth` opens the orbit view directly. The existing engine installation is required.

## Controls

TerraSim now opens on Earth in a fitted 1280 × 760 window. Both scenes use the same basic navigation: **drag to rotate, scroll to zoom, Home/R to reset**. Large direction and zoom buttons provide the same actions. Arrow keys also rotate; Tab/Shift-Tab focuses buttons and Enter activates them. Escape closes help/science panels, restores the interface, or exits advanced flight.

The Mont Blanc scene starts in safe guided navigation. Choose Summit, Glaciers, Valley or Whole area; camera pitch, zoom and altitude are bounded. Free flight is explicitly optional under **Fly (advanced)**: drag to look, WASD to move horizontally, Q/E for height, Shift for a modest speed boost. Flight is bounded to the available terrain patch and remains above its highest ground.

**Science** contains model selection, experiments, observer height, axial tilt, local Sun height, cloud visibility and date/reverse-time controls. The main interface only shows place/view selection, navigation and simple sunlight controls. **Help** explains the essentials. Full view can still be toggled with I and always retains visible exit/Home controls.

**Smooth** is the default graphics setting: 75% internal resolution with TSR, lower cloud ray counts and a 60 fps cap. **Detailed** raises internal resolution and cloud samples. The FPS display reports the running scene; it is not a performance guarantee. Terrain startup skips the unused planetary 8K materials. Cesium remains installed on disk but is disabled in this local demo because worldwide streaming is not configured.

## Scientific and rendering limits

The native solar calculation uses the USNO approximate solar-coordinate method, with UTC as a UT1 approximation. It is distinct from the browser edition's Astronomy Engine calculations. The native lunar-eclipse row explicitly refers to the browser laboratory instead of inventing an unimplemented prediction. Cloud imagery is recorded, not live weather. The orbital cloud layer blends opacity; it is not a global volumetric weather simulation. Native volumetric clouds are used in the local terrain scene. Displayed city-light radiance is increased for artistic dynamic-range compression. The native ground demonstration uses an approximate local tangent frame with a mean-radius curvature correction; it does not implement worldwide GIS streaming or a geoid/ellipsoid vertical-datum conversion.

The Cesium source has four compatibility fixes for Apple Clang 21 / UE 5.8: a singleton iterator lookup, removal of unreachable returns/breaks, a weak window capture initialized after construction, and an explicit enum default. The reproducible diff is in `Scripts/cesium-clang21.patch`. Engine source and security settings are not modified.

The installed engine intermittently reports an ICU/Slate cleanup crash when the asset-generation editor exits after saving. Assets must be checked using the completion markers and runtime independently; an editor exit code alone is insufficient. The launch script uses the supported `-ansimalloc` allocator option. A reproducible runtime crash in the engine scene-extension cleanup path was addressed for this project by setting `r.RDG.ParallelExecute=0` and `r.RDG.ParallelDestruction=0`; synchronous cleanup can reduce CPU throughput. The physical exposure range is matched by `r.EyeAdaptation.CachedLightingPreExposure=10`.

OBJ import units differ between first import and reimport in this engine. The generation script normalizes the terrain actor against the measured source width and asserts the final scene extent; uniform scaling preserves 1x vertical relief. Satellite and planetary textures remain resident because texture streaming selected overly coarse mips for the imported/scaled scene. This trades additional GPU memory for stable image detail.
